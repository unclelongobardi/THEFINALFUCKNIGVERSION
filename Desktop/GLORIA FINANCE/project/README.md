# GLORIA FINANCE

Una plataforma web moderna y elegante para explorar el ecosistema DeFi de Solana con análisis de riesgo en tiempo real.

## 🎯 Visión

GLORIA FINANCE ayuda a los usuarios a tomar mejores decisiones de inversión mostrando datos en tiempo real sobre pools de liquidez y vaults en Solana, categorizados por riesgo.

## ✨ Características

### 🎨 Diseño Moderno
- **Tema Oscuro**: Diseño elegante con colores neón (verde, púrpura, cian)
- **Responsive**: Optimizado para móviles y escritorio
- **Animaciones**: Transiciones suaves y efectos visuales atractivos
- **Fuentes Modernas**: Inter, Space Grotesk, Sora

### 📊 Funcionalidades
- **Exploración de Pools**: Tabla interactiva con pools y vaults de Solana
- **Filtros Avanzados**: Por protocolo, nivel de riesgo, APY, TVL
- **Análisis de Riesgo**: Sistema de puntuación de riesgo en tiempo real
- **Conexión de Wallet**: Integración preparada para wallets de Solana

### 🔍 Secciones Principales
1. **Hero Section**: Presentación impactante con gradientes animados
2. **About**: Descripción de la plataforma y su misión
3. **Solutions**: Cuatro pilares de servicios (Risk Curation, Ecosystem Design, Building Blocks, DeFi Ratings)
4. **Mission**: Declaración de misión y enfoque estratégico
5. **Research Process**: Timeline visual del proceso de investigación
6. **dApp**: Interfaz principal para explorar pools y vaults
7. **Footer**: Enlaces y información de contacto

## 🛠 Tecnologías

- **React 18** con TypeScript
- **Vite** para desarrollo rápido
- **Tailwind CSS** para estilos
- **Lucide React** para iconos
- **Google Fonts** (Inter, Space Grotesk, Sora)

## 🚀 Instalación y Desarrollo

### Prerrequisitos
- Node.js 18+ 
- npm o yarn

### Instalación
```bash
# Clonar el repositorio
git clone <repository-url>
cd gloria-finance

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

### Scripts Disponibles
```bash
npm run dev      # Servidor de desarrollo
npm run build    # Construir para producción
npm run preview  # Vista previa de producción
npm run lint     # Linting del código
```
